**Flag on the `needs_diagram` column:** every single one of the 169 sections in this database — 100%, across all 16 courses — has `needs_diagram: true` with a non-null `diagram_description`. Zero of them have a resolved `diagram_image_url`. That's not a plausible "this section genuinely needs an image" rate; it looks like the generation prompt biases the model toward always requesting a diagram, and the separate `fetchTextbookDiagramJob` (Google Image Search + AI candidate selection) never once successfully resolved an image against any of them. This is a real defect in the legacy pipeline worth carrying into the design of the replacement — the `needs_diagram` numbers above are accurate counts of the flag, but the flag itself doesn't appear to mean what it's supposed to mean.

## Worked-example / question types (top 3 courses by content volume)

The 3 courses with the most content are: GST 111, PHY 102, PHY 103.

This section is filled in by hand after a manual read of each course's full generated content (dumped to `docs/.legacy-textbook-baseline-content/<course_code>.md` by this script, not committed) — a conservative, human read of the actual prose, not a keyword/regex scan, per the request to undercount rather than inflate.

Methodology note: these are read directly from each course's full generated prose (13-14 sections each, ~33-36K characters), not detected by keyword search. Only patterns I could point to a specific passage for are listed; near-duplicate patterns within a course are merged into one entry rather than counted separately, per the "undercount, don't inflate" instruction. None of these are CBT-style multiple-choice questions — those live in the separate `Question` table (generated by a different job, `generateQuestions.job.ts`, not audited here) and never appear inside `GeneratedTextbookSection.content` itself.

### GST 111 — GST 111 (never published)

3 distinct types found:

1. **Scaffolded writing-construction tasks** — a numbered sequence ("Task 1... Task 2... Task 3...") that has the student build a sentence up in stages (simple → complex), each step checked against a stated criterion rather than an answer key (Sentence Construction section).
2. **Fill-in-the-blank correction drills with the answer explained inline** — a sentence with a bracketed choice, e.g. `"The group of researchers (study/studies) the data daily"`, immediately followed by the correct choice and the reasoning for it (Grammar and Usage section, concord and mood).
3. **Worked classification walkthroughs** — a sample (a full sentence, or words like "email"/"unhappy"/"notebook") is broken down piece by piece and each part labeled against a taught framework (lexical vs. grammatical word class; affixation/compounding/blending/clipping).

### PHY 102 — PHY 102 — Akademi Textbook

3 distinct types found:

1. **Direct numeric plug-in-and-solve** — given values are substituted straight into a named formula and multiplied out to a final answer, e.g. the Lorentz force "quick check" (F = qvB sinθ, 2×3×4×1 = 24).
2. **Calculus-based worked example** — a given function is differentiated to find a rate of change, then evaluated at a specific point, e.g. Faraday's Law (Φ(t) = 5t² + 2t → dΦ/dt → ε at t = 2s).
3. **Symbolic derivation / rearrangement** — starts from a general law and algebraically isolates a target variable rather than plugging in numbers, e.g. Gauss's Law applied to a sphere to isolate E.

### PHY 103 — PHY 103 — Akademi Textbook

4 distinct types found:

1. **Unit/scale conversion worked example** — a single given value run through two different conversion formulas (20°C converted to both Kelvin and Fahrenheit).
2. **Direct numeric plug-in-and-solve** — same pattern as PHY 102's type 1, e.g. Hooke's Law (k = F/x = 10N / 0.05m = 200 N/m) and buoyancy (100N rock, 30N displaced water → 70N apparent weight).
3. **Worked example + matching unsolved practice problem** — a fully worked example is immediately followed by a same-structure problem with new numbers and a hint, but no answer given, e.g. Hooke's Law's "Here is a practice problem for you: ... 15 Newtons ... 0.1 meters ... (Hint: divide the force by the distance)."
4. **Worked example + Socratic predict-then-check question, answered inline** — a "try this yourself" conceptual prompt that is answered within the same paragraph rather than left open, e.g. Bernoulli's equation's "what happens if the water slows down?" immediately resolved by the same reasoning chain.
